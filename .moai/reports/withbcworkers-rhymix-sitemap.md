# 부천지역노동공제회 홈페이지 구성안 (Rhymix 기준)

- 작성일: 2026-10-22
- 분석 자료: 카카오톡 단체방 "[팀채팅]일하는사람들과"함께" 소통방" 내보내기 파일 (메시지 1,934건, 2025-02-18 ~ 2026-10-21, 참여자 68명)
- 함께 확인한 자료: 현행 홈페이지 `withbcworkers.kr` 공개 메뉴, Rhymix 저장소(https://github.com/rhymix/rhymix) 2.1.39의 코어 모듈 32개
- 본문의 `L숫자`는 대화 파일의 줄 번호이다. 개인 이름과 연락처는 싣지 않았다.

## 요약

- 공제회는 이미 `withbcworkers.kr`로 홈페이지를 개편해 운영 중이다. 이 사이트는 Rhymix가 아니라 Rails 기반 SaaS 빌더로 만들어져 있다. 따라서 Rhymix 도입은 신규 구축이 아니라 이전 작업이다.
- 회원들이 가장 자주 겪은 불편은 "어디서 신청하나요?"였다. 신청 경로가 Google Forms, bit.ly, Notion, 네이버 폼, 문자로 흩어져 있기 때문이다.
- 구성안은 상위 메뉴 7개(함께 소개, 노동공제, 노동상담, 활동, 소식, 자료실, 회원공간)로 짰다. 메인 화면 맨 위에는 '지금 신청 중' 영역을 둔다.
- 달력, 설문형 신청서, 카카오·네이버 로그인, 회비 결제, 뉴스레터 발송은 Rhymix 코어에 없다.

## 1. 대화 분석 결과

### 1.1 단체 개요

- 정식 명칭은 사단법인 일하는사람들과함께(부천지역노동공제회)이며, 노동공제연합 (사)풀빵의 회원 조직이다 (L10, L3548).
- 설립 목적은 "작은사업장 노동자, 프리랜서 등 일하는 모든 사람들이 노동의 권리를 함께 지키고자 창립"으로 소개된다 (L2577).
- 회원은 작은 사업장 노동자, 프리랜서, 단체 활동가, 아파트 미화·경비 노동자, 이동 노동자 등이다 (L737, L4368, L4786).
- 운영 구조
  - 공동대표 3인 (L728)
  - 이사회: 회차를 매겨 열며 회원 누구나 참관할 수 있다 (L3446, L6097)
  - 정기총회: 위임장과 선거관리위원회를 둔다. 2026-01-31에 임원 선거를 치렀다 (L2888, L3071)
- 협력 기관
  - 부천시비정규직노동자지원센터: 주요 행사 장소이자 공동 사업 파트너
  - 공공상생연대기금: 2026년 2천만 원 지원 (L2863)
  - 부천희망재단, 부천시일쉼지원센터: 협약 기관
  - 법률사무소 지담: MOU (L3494)
  - 협약 의원·가게

|---|---|---|

### 1.3 회원들이 겪는 불편

구성안의 우선순위는 아래 근거를 바탕으로 정했다.

1. 신청 경로를 찾지 못한다. "연극관람. 어디에 신청하나요"(L956), "선물신청 어디서 하나요?"(L3139) 같은 질문이 기간 전체에 걸쳐 반복된다. 공유된 링크 가운데 Google Forms만 66건이다.
2. 중요한 안내를 놓친다. 명절선물 신청을 문자로만 안내해 놓친 회원이 있었고, 선물이 잘못된 주소로 배송된 일도 있었다 (L3145, L3190). 회원이 연락처와 주소를 직접 고칠 수 있어야 한다.
3. 혜택 기준이 한곳에 없다. 공제 혜택을 최소 4차례 다시 공지했다 (L1025, L1670, L2795, L4378). 경조사수당은 10만 원(L1014 부근)과 20만 원(L4378) 두 금액이 모두 나오는데, 4/11에 혜택이 바뀌었기 때문으로 보인다 (L4070).
4. 신청이 아직 열려 있는지 알기 어렵다. "공지가 없으면 아직 신청 가능한 겁니다"(L650)라는 안내가 있었고, 같은 포스터를 여러 번 다시 올렸다 (L4781).
5. 상담을 맡길 비공개 창구가 없다. 상담 질문이 단체방에 올라와 운영진이 개인 대화로 옮겼다 (L4225).

### 1.4 현행 홈페이지

- 주소는 `https://withbcworkers.kr`이다. 구 주소 `withbcworkers.mycafe24.com`은 현재 403 응답을 돌려준다.
- 플랫폼: 응답 쿠키(`ahoy_visitor`, `withbcworkers_kr_mixon_session_v2`)와 Turbo·Tailwind 에셋으로 보아 Rails 기반 SaaS 빌더이다. Rhymix나 XE 흔적은 보이지 않는다.
- 공개 메뉴는 다음과 같다.
  - 소개: 연혁, 정관, 함께하는사람들, 협약기관
  - 노동공제품목: 기본공제(풀빵 1호), 적립형공제(풀빵 2호), 비상금고(풀빵 3호)
  - 공지·소식: 공지사항, 활동소식, 자료실(문서·사진), 뉴스레터
  - 동아리활동: 동아리활동소식, 동아리원 모집
  - 노동상담게시판, 마이페이지
- 회원 구조: 카카오·네이버 계정으로 가입하면 일반회원이 되고, 운영진이 확인하면 공제회원으로 등급을 올린다. 일반회원은 상담게시판에만 글을 쓸 수 있다 (L4444-4456).

### 2.1 메인 화면 배치

위에서부터 회원 불편이 큰 순서로 배치한다.

1. **지금 신청 중**: 마감 전 신청만 카드 형태로 보여 준다. 1.3의 1번과 4번 불편에 직접 대응한다.
2. 이번 달 일정과 다음 노동상담 날짜 (고정 배너)
3. 공지사항 최신 글
4. 바로가기: 공제 혜택 / 가입하기 / 상담 신청 / 카카오채널 문의
5. 활동 갤러리 최신 사진

## 3. Rhymix 코어로 해결되지 않는 기능

판단 근거는 Rhymix 2.1.39 `modules/` 디렉터리의 모듈 32개와 각 모듈의 `conf/info.xml` 설명이다. 외부(서드파티) 모듈은 검증하지 않았다.

| 필요 기능 | Rhymix 코어 | 제안 |
|---|---|---|
| 일정 달력 | 없음 | 게시판과 날짜 확장필드(extravar)로 목록을 구성한다. 달력 화면이 필요하면 스킨을 따로 만들거나 외부 모듈을 찾는다 (미검증) |
| 설문형 신청서 | 없음 (`poll`은 단순 투표) | Google Forms를 계속 쓰고, '지금 신청 중' 게시판에 링크를 모은다 |
| 카카오·네이버 로그인 | 코어 모듈 목록에 없음 | 현행 사이트가 쓰는 기능이므로 외부 모듈을 찾거나 이메일 가입으로 전환한다 (미검증) |
| 회비 결제(CMS) | 없음 | 현행처럼 `mrmweb` 외부 링크를 유지한다 |
| 뉴스레터 발송 | 없음 (`advanced_mailer`는 발송 관리·기록 기능) | 망고보드 등 외부 도구로 제작하고, 사이트에는 게시판으로 게시한다 |
| 문자·푸시 알림 | `advanced_mailer`에서 관리. 단, 발송 업체 연동이 필요하다 | 명절선물 신청처럼 놓치면 안 되는 안내에 쓴다 |

운영 환경으로는 PHP 7.4 이상과 MySQL 또는 MariaDB가 필요하다 (README 기준. `common/composer.json`에는 `php >=7.2.5`로 적혀 있다). 지금처럼 SaaS가 운영을 대신하는 구조와 달리, 호스팅·백업·보안 업데이트를 공제회가 직접 맡아야 한다.

## 4. 결정 전 검토 사항

1. **Rhymix로 옮기는 목적.** 현행 사이트는 최근 개편을 마쳤고 소셜 로그인, 회원 등급, 달력, PDF 보기를 이미 갖추고 있다. Rhymix로 옮기면 소셜 로그인과 달력은 오히려 따로 마련해야 한다. 이전 목적이 비용 절감, 데이터 소유, 기능 확장 중 무엇인지에 따라 판단이 달라진다.
2. **기존 게시글 이전.** Rhymix의 `importer` 모듈은 XE용 XML 형식을 받는 것으로 보인다 (미검증). Rails SaaS의 게시글을 옮기려면 내보내기와 변환 작업이 따로 필요할 수 있다.
3. **공제 혜택 기준 확정.** 대화에 경조사수당이 10만 원과 20만 원으로 함께 나오므로, 혜택 페이지를 만들기 전에 사무국이 현재 기준을 확정해야 한다.

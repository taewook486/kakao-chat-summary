Windows 10 이상에서 설치 가능합니다. (WSL 사용도 추천되지만, 네이티브 설치가 가장 간단합니다.)
#### 권장 방법 1: PowerShell 사용 (가장 간단)
관리자 권한으로 PowerShell을 열고 다음 명령어를 실행하세요.
```powershell
irm https://claude.ai/install.ps1 | iex
```
- 최신 버전 강제 설치 시:
irm https://claude.ai/install.ps1 | iex -Force latest
#### 권장 방법 2: CMD 사용
명령 프롬프트(CMD)를 열고 실행:
```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
#### 다른 방법
1. **WinGet 사용** (Windows Package Manager가 설치되어 있어야 함):
winget install Anthropic.ClaudeCode
2. **NPM 사용** (Node.js 18+가 설치되어 있어야 함):
npm install -g @anthropic-ai/claude-code
설치 후 PowerShell/CMD를 재시작하거나 PATH를 새로고침하세요. (보통 자동으로 적용됩니다.)

```bash

- 버전 정보와 설치 상태를 확인합니다.

### 인증 및 로그인

/login

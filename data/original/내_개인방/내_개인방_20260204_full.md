### 주요 기능
Taskmaster는 AI를 활용한 작업 관리 도구로, 복잡한 소프트웨어 프로젝트를 작은 작업 단위로 분해하고 관리합니다. Cursor, Lovable, Windsurf, Roo 등의 AI 코드 에디터와 통합되어 작동하며, 다음과 같은 핵심 기능을 제공해요:
- **PRD(프로젝트 요구사항 문서) 기반 자동 작업 생성**: PRD 문서를 분석해 작업 목록을 자동으로 만들어줍니다.
- **작업 관리 기능**: 작업 추가/삭제, 상태 변경(예: backlog → in-progress), 태그 이동, 의존성 설정 등.
- **AI 연구 도구**: 실시간으로 기술 동향이나 구현 방법을 조사합니다. 예를 들어, "JWT 인증의 최신 베스트 프랙티스"를 검색해 제안.
- **컨텍스트 기반 분석**: 프로젝트 파일(예: src/api.js)을 읽고 맞춤형 연구나 코드 제안을 합니다.
- **다양한 AI 모델 지원**: Anthropic(Claude), OpenAI, Google Gemini, Perplexity, xAI, OpenRouter 등 호환.
- **MCP 지원**: 에디터 내에서 직접 AI 작업을 수행할 수 있게 해줍니다.
- **도구 로딩 최적화**: 컨텍스트 토큰 사용량을 줄이기 위해 'all'(36개 도구, ~21,000 토큰), 'standard'(15개, ~10,000 토큰), 'core'(7개, ~5,000 토큰) 모드나 커스텀 설정 가능.
이 도구는 AI가 큰 작업을 처리할 때 발생하는 맥락 상실이나 오류를 최소화하며, "AI의 프로젝트 매니저" 역할을 합니다.
### 설치 방법
두 가지 주요 방식으로 설치할 수 있어요. MCP 방식이 에디터 통합에 가장 편리합니다.
#### 1. MCP 방식 (권장, 에디터 통합)
에디터의 MCP 설정 파일에 JSON을 추가하세요. API 키(ANTHROPIC_API_KEY 등)를 환경 변수로 설정합니다.
- **Cursor / Windsurf / Q CLI 예시**:
```json
{
"mcpServers": {
"task-master-ai": {
"command": "npx",
"args": ["-y", "task-master-ai"],
"env": {
"ANTHROPIC_API_KEY": "YOUR_ANTHROPIC_API_KEY_HERE",
"PERPLEXITY_API_KEY": "YOUR_PERPLEXITY_API_KEY_HERE",
"OPENAI_API_KEY": "YOUR_OPENAI_KEY_HERE",
"TASK_MASTER_TOOLS": "standard"  // 도구 모드 선택
}
```
- **VS Code 예시**:
"servers": {
"env": { ... },  // 위와 동일
"type": "stdio"
설정 후, 에디터에서 MCP 서버를 활성화하고 "Initialize taskmaster-ai in my project" 명령으로 초기화하세요.
#### 2. CLI 방식
터미널에서:
```bash
# 전역 설치
npm install -g task-master-ai
# 또는 로컬 설치
npm install task-master-ai
# 프로젝트 초기화
task-master init  # 또는 npx task-master init
### 사용 예시
AI 채팅창(에디터 내)이나 CLI에서 명령어를 사용합니다. 복잡한 프로젝트는 .taskmaster/docs/prd.txt에 PRD를 작성하세요.
- **PRD 파싱**: 채팅에서 "Can you parse my PRD at scripts/prd.txt?" 입력, 또는 CLI: `task-master parse-prd your-prd.txt`
- **작업 목록 확인**: `task-master list` 또는 채팅: "Can you show me tasks 1, 3, and 5?"
- **다음 작업 확인**: `task-master next` 또는 채팅: "What's the next task I should work on?"
- **연구 요청**: 채팅: "Research the latest best practices for implementing JWT authentication with Node.js" 또는 CLI: `task-master research "What are the latest best practices for JWT authentication?"`
- **작업 확장**: "Can you help me expand task 4?"
- **태그 이동**: `task-master move --from=5 --from-tag=backlog --to-tag=in-progress`
### MCP 서버 설정 방법
1. 에디터 MCP 파일에 JSON 추가 (위 설치 참조).
2. API 키를 .env나 env 섹션에 입력.
3. TASK_MASTER_TOOLS 환경 변수로 도구 모드 설정 (all, standard, core 등).
4. 에디터에서 서버 활성화 후 초기화 명령 실행.
이 설정으로 에디터 내에서 Taskmaster를 MCP 서버처럼 사용 가능합니다.

Claude Code(Anthropic의 Claude AI 코딩 환경) 사용자에게 특히 유용합니다.
- **지원 모델**: claude-code/opus, claude-code/sonnet.
- **API 키 없이 로컬 사용**: Claude Code CLI 설치 후.
- **설치 명령**:
claude mcp add taskmaster-ai --scope user \

이 통합으로 코드 생성 오류를 90% 줄일 수 있으며, PRD 분석과 작업 우선순위화가 자동화됩니다.

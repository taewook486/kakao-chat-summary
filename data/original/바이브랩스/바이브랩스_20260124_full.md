Why 1: "왜 칭찬받고 싶어요?"
→ "그냥요..."
Why 2: "정말요? '그냥'이라는 건 없어요.
뭔가 불안한 게 있지 않나요?"
→ ...
Why 3: (계속 파고듦)

[예레미야] [오전 11:35]  Remotion Agent Skills
https://x.com/i/grok/share/9ec3111ebfa1415b90f77fb3d741b6b0
**Remotion Skills** (정확히는 **Remotion Agent Skills**)는 Remotion 프레임워크를 위한 AI 에이전트 전용 "스킬 세트"입니다.
Remotion 자체는 **React**로 비디오를 프로그래밍 방식으로 만드는 오픈소스 프레임워크예요. (React 컴포넌트를 작성하면 각 프레임을 렌더링해서 MP4 영상으로 출력하는 방식입니다. After Effects 같은 타임라인 편집 대신 코드로 애니메이션·그래픽·자막 등을 만들 수 있죠.)
그런데 2026년 1월에 새로 출시된 **Agent Skills** 기능은 이 Remotion을 **Claude Code** (Anthropic의 CLI 기반 코딩 에이전트) 같은 AI에게 가르쳐주는 지식 팩이에요.
- 설치 명령어:
npx skills add remotion-dev/skills
(또는 Remotion 프로젝트 생성 시 옵션으로 추가 가능)
이 스킬을 추가하면 Claude Code가 Remotion의 아키텍처, 애니메이션 API (예: Remotion의 <Sequence>, <Animation>, Three.js 연동 등), 베스트 프랙티스 (폰트 로딩, 자막 표시, 3D 콘텐츠 등)를 깊이 이해하게 됩니다.
결과적으로 **코딩을 거의 안 해도** 자연어 프롬프트만으로 애니메이션 영상을 만들 수 있게 돼요.
예: "TikTok 스타일로 제품 소개 영상 만들어줘, 자막은 단어별 하이라이트 되고 그래프도 넣어" → Claude가 Remotion 프로젝트를 자동으로 생성·수정·렌더링.
최근 (2026년 1월 기준) 이 기능이 엄청 화제가 됐고, 많은 사람들이 "AI가 모션 그래픽 디자이너가 됐다"라고 평가하고 있어요.
예시 영상들 (Remotion으로 만든 애니메이션 샘플):
Claude Code + Remotion Skills 데모 관련 이미지:
더 자세한 사용법은 Remotion 공식 문서 (https://www.remotion.dev/docs/ai/skills)나 Claude Code와 함께 실습해 보는 게 제일 좋아요!

- Auto (자동 실행) → 코드 작업 시 실수 방지 최고!
- **강력한 통합(MCP 서버)**: GitHub, Linear, Slack, REST API, 로컬 파일, Craft 문서 등을 동시에 연결해서 에이전트가 실제 프로젝트와 자연스럽게 연동됨.

[예레미야] [오전 11:41] 감사합니다. 저는 dgx spark 가 128gb 램으로 사용 가능해서 그냥 Qwen3-TTS-12Hz-1.7B-Base 으로 설치 했어요.
===== 설치 스크립트 ====================
#!/bin/bash
set -euo pipefail
# start_qwen3_tts_base.sh - Qwen3 TTS Base 서버 기동 (Voice Clone 지원)
# 참조 음성으로 Zero-shot 음성 복제 가능
DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# Config
MODEL_NAME="${MODEL_NAME:-Qwen/Qwen3-TTS-12Hz-1.7B-Base}"
MODEL_DIR="${MODEL_DIR:-/data/models/qwen3-tts}"
SERVER_PORT="${SERVER_PORT:-8990}"
CONTAINER_NAME="${CONTAINER_NAME:-qwen3-tts}"
NGC_IMAGE="nvcr.io/nvidia/pytorch:25.11-py3"
HF_CACHE="${HOME}/.cache/huggingface"
LOCAL_MODEL_DIR="/models/base-local"
echo "=== Qwen3 TTS Base (Voice Clone) 기동 ==="
echo ""
echo "  모델: ${MODEL_NAME}"
echo "  포트: ${SERVER_PORT}"
echo "  컨테이너: ${CONTAINER_NAME}"
# 1. 기존 컨테이너 정리
if sudo docker ps --format '{{.Names}}' | grep -qx "${CONTAINER_NAME}"; then
echo "이미 실행 중입니다. 정지 후 재시작: ./stop_qwen3_tts.sh && ./start_qwen3_tts_base.sh"
exit 1
fi
if sudo docker ps -a --format '{{.Names}}' | grep -qx "${CONTAINER_NAME}"; then
sudo docker rm "${CONTAINER_NAME}" 2>/dev/null || true
# 2. 디렉터리 준비
sudo mkdir -p "${MODEL_DIR}"
sudo chown -R "$(whoami):$(whoami)" "${MODEL_DIR}"
mkdir -p "${HF_CACHE}"
# 3. 컨테이너 기동
echo "컨테이너 기동 중..."
sudo docker run -d \
--name "${CONTAINER_NAME}" \
--gpus all \
--shm-size=4g \
-p "${SERVER_PORT}:${SERVER_PORT}" \
-v "${DIR}:/workspace/tts" \
-v "${MODEL_DIR}:/models" \
-v "${HF_CACHE}:/root/.cache/huggingface" \
-v "${HOME}/.cache/pip:/root/.cache/pip" \
-e NVIDIA_VISIBLE_DEVICES=all \
"${NGC_IMAGE}" \
bash -c "
pip install --pre --upgrade --force-reinstall torch torchvision torchaudio \
--index-url https://download.pytorch.org/whl/nightly/cu130 && \
pip install --no-deps qwen-tts && \
pip install -q transformers==4.57.3 accelerate==1.12.0 safetensors \
flask soundfile librosa sox onnxruntime tokenizers huggingface-hub>=0.23.0 && \
echo '=== 모델 다운로드 ===' && \
huggingface-cli download '${MODEL_NAME}' --local-dir ${LOCAL_MODEL_DIR} && \
echo '=== 서버 기동 ===' && \
python3 /workspace/tts/tts_server.py \
--model-name ${LOCAL_MODEL_DIR} \
--model-dir /models \
--port ${SERVER_PORT} \
--device cuda:0
"
echo "컨테이너 ID: $(sudo docker ps -q -f name=${CONTAINER_NAME})"
# 4. 서버 대기
echo "서버 기동 대기 중... (첫 실행 시 수 분 소요)"
MAX_WAIT=600
WAITED=0
while [ $WAITED -lt $MAX_WAIT ]; do
if ! sudo docker ps --format '{{.Names}}' | grep -qx "${CONTAINER_NAME}"; then
echo "컨테이너가 종료되었습니다!"
sudo docker logs --tail 30 "${CONTAINER_NAME}" 2>&1
if curl -sf "http://127.0.0.1:${SERVER_PORT}/health" > /dev/null 2>&1; then
echo "=== 서버 기동 완료 (Voice Clone 모드) ==="
echo "API:"
echo "  GET  http://127.0.0.1:${SERVER_PORT}/health"
echo "  POST http://127.0.0.1:${SERVER_PORT}/tts/clone"
echo "Voice Clone 테스트:"
echo "  curl -X POST http://127.0.0.1:${SERVER_PORT}/tts/clone \\"
echo "    -H 'Content-Type: application/json' \\"
echo "    -d '{\"text\":\"테스트\", \"ref_audio_path\":\"/workspace/tts/ref.wav\"}' \\"
echo "    -o cloned.wav"
echo "로그:"
echo "  sudo docker logs -f ${CONTAINER_NAME}"
exit 0
sleep 5
WAITED=$((WAITED + 5))
if [ $((WAITED % 30)) -eq 0 ]; then
echo "  대기 중... (${WAITED}/${MAX_WAIT}초)"
sudo docker logs --tail 2 "${CONTAINER_NAME}" 2>&1 | sed 's/^/    /'
done
echo "서버 기동 타임아웃 (${MAX_WAIT}초)"
echo "로그 확인: sudo docker logs ${CONTAINER_NAME}"

[예레미야] [오후 10:12] 1. GLM-4.7 모델 개요
1.1. 주요 특징
Zhipu AI 개발의 대형 언어 모델로, 코딩·추론·에이전트 작업에 특화. 다국어 지원, 컨텍스트 길이 131,072 토큰. SWE-bench 73.8%, Terminal Bench 2.0 41% 성능.
1.2. 아키텍처 및 파라미터
MoE 아키텍처, 총 358B 파라미터(포워드 시 32B 활성화). FP8·bfloat16 지원. 경량 버전 GLM-4.7 Flash(30B).
2. VRAM 요구사항
2.1. Precision에 따른 요구사항
FP16: 1,024 토큰 기준 731GB (11x H100). INT8: 370GB (6x H100). INT4: 190GB (3x H100). 4-bit 양자화: ~130GB (2x A100). Flash 버전: 16GB VRAM 이상.
2.2. 추가 고려사항
컨텍스트 증가 시 KV 캐시로 VRAM 추가 필요 (128K 토큰: 1TB+). 다중 GPU(텐서 병렬)·오프로딩 추천. CPU 오프로딩 시 속도 저하.
3. 사내 코딩용 추천 설정
3.1. 배포 추천
로컬 배포(vLLM·SGLang). Flash 버전 저전력 적합. Temperature 0.7, Top-p 1.0 설정.
3.2. 보안 및 최적화
Hugging Face 다운로드, 4-bit 양자화로 VRAM 절감. 생각 모드 활성화로 안정성 향상.

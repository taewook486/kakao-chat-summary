[허인범] [오전 12:36] • OpenClaw가 같은 **세션(예: 너와 나의 DM)**에서 여러 메시지를 처리할 때 충돌 안 나게 차례/합치기/중단를 정함
• 기본은 collect:  • 잠깐 몰아서 들어온 DM을 한 번에 합쳐서 한 번의 답변으로 처리
• 느린 것처럼 느껴지면 사실 이 모드일 때가 많음
• 다른 모드들:  • followup: 지금 답변 끝난 뒤 다음 답변으로 처리
• steer: 현재 진행 중인 답변에 새 메시지를 즉시 끼워 넣음(스트리밍 시 중간에 반영 느낌)
• interrupt: 지금 돌아가던 답변을 즉시 취소하고 새 메시지를 우선 처리
• steer-backlog(steer+backlog): 지금 끼워 넣고, 뒤에 추가 followup도 남김
• 옵션도 있음: debounce, cap, drop (너무 몰리는 메시지 처리 방식)
• 적용은 채팅에서 /queue collect|followup|steer|interrupt 이렇게 즉시 바꾸면 되고, 기본/지속 설정은 ~/.openclaw/openclaw.json 안 messages.queue 쪽에서 관리돼
실제로 “입력 바로바로” 느낌을 원하면 /queue interrupt 또는 /queue steer가 제일 직관적이야.

• 기본 확인: openclaw status
• 강제 고정:openclaw config set --json gateway.mode '"local"'
• Runtime: direct가 유지되는 상태가 맞는지 openclaw status로 확인
2) 큐 빠른 응답 세팅(영구)
• 즉시 반응 우선:openclaw config set --json messages.queue.mode '"interrupt"'
openclaw config set --json messages.queue.debounceMs 300
openclaw config set --json messages.queue.cap 20
openclaw config set --json messages.queue.drop '"summarize"'
• 채널별로만 쓰고 싶으면:openclaw config set --json messages.queue.byChannel.telegram '"interrupt"'
3) Telegram 스트리밍 더 자연스럽게
openclaw config set --json channels.telegram.streamMode '"partial"'
openclaw config set --json channels.telegram.blockStreaming false
4) 채팅에서 즉시 전환(세션 단위)
• /queue interrupt → 가장 빠른 느낌
• /queue steer → 중간 반영 느낌
• /queue collect → 묶어서 차분하게 처리
원하면 내가 지금 바로 /queue interrupt 기준으로 네 세팅만 딱 맞는 스크립트 한 줄로 깔아줄게.

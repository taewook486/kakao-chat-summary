[예레미야] [오후 1:26] # [논문 요약] RESEEK: A SELF-CORRECTING FRAMEWORK FOR SEARCH AGENTS WITH INSTRUCTIVE REWARDS
- **저자**: Shiyu Li, Yang Tang, Yifan Wang, Peiming Li, Xi Chen (Tencent & Tsinghua University)
- **발표일**: 2025년 10월 29일 (arXiv:2510.00568v2)
- **주제**: 에이전트 스스로 오류를 평가하고 교정(Self-correcting)하는 LLM 기반 검색 에이전트 강화학습 프레임워크 제안
## 1. 연구 배경 및 문제 정의
- 기존 대형 언어 모델(LLM) 기반 검색 에이전트는 복잡한 다단계 지식 탐색 시 주로 강화학습(RL)을 사용하지만, 최종 결과에 따른 **희소 보상(Sparse rewards)**에 의존하는 경향이 있습니다.
- 이로 인해 탐색 초기에 잘못된 검색 쿼리나 방향에 빠질 경우, 스스로 오류를 인지하고 궤도를 수정하지 못한 채 오답으로 직행하는 치명적인 한계(Cascading errors)가 발생합니다.
## 2. 핵심 제안: ReSeek 프레임워크
본 논문은 에이전트가 정보 탐색 중 오류를 스스로 파악하고 동적으로 검색 전략을 수정할 수 있는 **ReSeek 프레임워크**를 제안합니다.
- **JUDGE 메커니즘 (자가 평가 및 수정)**: 에이전트는 정보를 검색한 후 의무적으로 `<judge>` 액션을 호출해 방금 찾은 정보가 유용한지 평가(`Yes` 또는 `No`)합니다. 정보가 쓸모없다면 해당 내용을 문맥에서 제외하고 즉시 새로운 전략으로 재검색(Re-plan)을 수행합니다.
- **지시적 과정 보상 (Instructive Process Rewards)**: 에이전트의 올바른 자가 평가 능력을 기르기 위해 중간 과정마다 **밀집 보상(Dense reward)**을 부여합니다. 외부 리랭커(Reranker) 모델을 통해 현재 정보와 정답 간의 객관적인 유용성을 측정하고, 에이전트의 판단이 이 기준(Ideal Judgment)과 일치할 때 보상을 제공합니다.
- **구조화된 프롬프팅**: `<think>`, `<search>`, `<judge>`, `<answer>`의 엄격한 포맷을 강제하여, 에이전트가 자가 수정 추론 루프를 안정적으로 수행하도록 유도합니다.
## 3. 새로운 벤치마크: FictionalHot
- **데이터 오염 문제 극복**: 기존 QA 벤치마크 데이터셋은 LLM이 사전 학습 단계에서 이미 정답을 암기했을 가능성이 높아 모델의 '순수한 탐색 및 추론 능력'을 평가하기 어렵습니다.
- **FictionalHot 구축**: 이를 방지하기 위해 실제 엔티티를 그럴듯한 가상의 엔티티(Fictional Entities)로 모두 교체하고, 가상의 위키피디아 문서를 생성해 폐쇄형 평가 환경을 만들었습니다. 이를 통해 철저히 모델의 절차적 독해 및 추론 능력만을 검증합니다.
## 4. 주요 실험 결과
- **압도적인 SOTA 달성**: Qwen2.5 (3B, 7B) 모델에 적용한 결과, NQ, HotpotQA, 2Wiki 등 8개의 오픈 도메인 QA 벤치마크에서 기존 최신 모델(Search-R1, ZeroSearch 등)을 크게 능가하는 정확도를 기록했습니다. (특히 여러 번 검색이 필요한 다중 홉(Multi-hop) 환경에서 강력함)
- **탐색 횟수(Turn)와 자가 수정의 시너지**: 일반 베이스라인 모델들은 검색 기회(Turn)가 늘어나도 성능이 정체되는 반면, ReSeek은 턴 수가 늘어날수록 `JUDGE` 메커니즘을 통한 지속적인 오류 보정이 이루어져 정답률이 단조 상승했습니다.
- **FictionalHot 평가**: 사전 지식에 의존할 수 없는 FictionalHot 환경에서도 모델 파라미터 크기(3B vs 7B)와 상관없이 일관된 성과를 보여 암기력이 아닌 본질적 추론 능력이 향상됨을 입증했습니다.
- **안정적인 훈련 알고리즘 (GRPO)**: 긴 사고 과정(CoT) 강화학습 시 PPO 알고리즘은 정책 붕괴(Policy Collapse)를 겪었으나, GRPO 알고리즘을 사용해 붕괴 없이 안정적이고 우수한 성과를 달성했습니다.

Claude Code의 코딩 성능을 개선합니다.

가정을 명확히 밝히고, 여러 해석을 제시하며, 혼란 시 질문을 합니다.
2.1.2 Simplicity First
최소한의 코드로 문제를 해결합니다.
불필요한 추상화나 기능을 피합니다.
2.1.3 Surgical Changes
필요한 부분만 수정합니다.
기존 코드를 불필요하게 리팩토링하지 않습니다.
2.1.4 Goal-Driven Execution
작업을 검증 가능한 목표로 변환합니다.
테스트를 통해 성공 여부를 확인합니다.

CLAUDE.md: 핵심 가이드라인 파일입니다.

README.md: 설치 및 사용 방법을 설명합니다.

Claude Code 플러그인으로 추가하는 방법을 권장합니다.

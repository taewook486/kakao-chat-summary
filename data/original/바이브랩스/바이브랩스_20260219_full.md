[예레미야] [오후 12:31] Claude Code(Anthropic의 Claude AI의 코드 중심 워크플로우 환경)에서 **MCP**(Model Context Protocol, Figma의 MCP 서버)를 통해 Figma를 공식 지원하게 되면서, 디자인과 코드 간의 왕복 작업이 훨씬 강력해졌습니다. 이는 최근 Figma와 Anthropic의 공식 파트너십으로 출시된 기능("Code to Canvas" 또는 "Claude Code to Figma")입니다.
### 주요 기능
- **코드 → Figma 디자인 변환 (Code to Canvas)**: Claude Code에서 생성한 실제 동작하는 UI(React, HTML/CSS 등 코드 기반 프로토타입)를 직접 Figma 파일로 보내서 **완전히 편집 가능한 디자인 프레임**으로 변환할 수 있습니다. 예를 들어 Claude Code에서 "Send this to Figma"라고 입력하면 실행 중인 브라우저 화면을 캡처해 Figma에 붙여넣기 가능. 정적 목업이 아닌 실제 구현된 UI를 디자인으로 가져와서 디자이너가 수정하거나 리뷰할 수 있습니다.
- **Figma 디자인 → 코드 생성 (Design to Code)**: Figma 파일의 디자인 컨텍스트(레이어, 컴포넌트, 스타일 등)를 Claude Code에서 직접 참조해서 더 정확한 프로덕션 레벨 코드 생성 가능. AI가 디자인 시스템에 맞춰 코드 자동 조정/정렬.
- **실시간 협업 강화**: 개발자가 Claude Code에서 작업한 결과를 즉시 Figma로 push하면 디자인 리뷰가 실제 구현 기반으로 이뤄집니다. 반대로 디자이너는 Figma에서 Claude를 활용해 다이어그램이나 컴포넌트 생성(특히 FigJam에서 프롬프트로 editable 다이어그램 만들기).
- **기타**: Figma 파일 접근, 선택된 프레임에서 코드 추출, UI 캡처 등.
이전에는 디자인과 코드가 분리되어 번거로웠지만, 이제 Claude Code와 Figma가 양방향으로 연결되어 "code AND canvas" 워크플로우가 가능해졌습니다.
### 별도의 호스팅 서버 없이 Figma에서 서비스 가능한가?
네, 완전히 가능합니다!
Figma가 공식 remote MCP 서버(https://mcp.figma.com/mcp)를 제공하기 때문입니다.
- 과거에는 로컬 MCP 서버(데스크톱 앱 설치 필요)를 돌려야 했지만, 이제 브라우저만으로 원격 서버 연결 가능 → 별도 호스팅 서버나 로컬 설치 없이 바로 사용.
- 연결 방법: Claude Code에서 /mcp 명령어로 Figma MCP 추가 → 인증만 하면 연결. Figma 쪽에서도 간단히 활성화.
- 결과적으로 Claude Code의 AI 기능을 Figma 안에서 직접 활용하거나, Claude Code에서 Figma 파일을 실시간으로 읽고 쓰는 "서비스"처럼 사용할 수 있습니다. Anthropic 서버와 Figma 서버가 백엔드를 담당하니 사용자 측 별도 인프라 필요 없음.

[바이브랩스 랩장] [오후 10:29] ## 8) Slack App 만들기(토큰 발급)
Telegram과 별개로 **Slack 채널**도 연결할 수 있습니다. Slack은 토큰이 두 개 필요합니다. ([OpenClaw](https://docs.openclaw.ai/channels/slack))
1. [Slack API 사이트](https://api.slack.com/apps)에서 **Create New App** → **From scratch** 선택
2. App 이름과 워크스페이스 지정
3. **Socket Mode** 활성화 (좌측 메뉴 Settings > Socket Mode)
- App Token(`xapp-...`) 생성 시 `connections:write` scope 추가
- 생성된 **App Token**을 복사해 둡니다.
4. **OAuth & Permissions** 메뉴에서 Bot Token Scopes 추가:
- `app_mentions:read`, `channels:history`, `channels:read`
- `chat:write`, `groups:history`, `groups:read`
- `im:history`, `im:read`, `im:write`
- `mpim:history`, `mpim:read`
- `reactions:read`, `reactions:write`
- `users:read`
5. **Install to Workspace** 클릭 → **Bot Token**(`xoxb-...`)을 복사해 둡니다.
6. **Event Subscriptions** 메뉴에서 다음 Bot Events 구독:
- `app_mention`
- `message.channels`, `message.groups`, [`message.im`](http://message.im), `message.mpim`
- `reaction_added`, `reaction_removed`
- `member_joined_channel`, `member_left_channel`
- `channel_rename`
- `pin_added`, `pin_removed`
7. **App Home** 메뉴에서 **Messages Tab** 활성화 (DM 수신용)

1. 스크립트 생성
아래 내용을 ~/.claude/statusline.py로 저장:
#!/usr/bin/env python3
import json, os, subprocess, sys, time
CACHE = "/tmp/claude-usage.json"
BLOCKS = " ▏▎▍▌▋▊▉█"
def bar(pct, width=8):
"""width=8 × 8단계 = 64칸 해상도 프로그레스 바"""
pct = max(0.0, min(100.0, float(pct or 0)))
total = round(width * 8 * pct / 100)
full, frac, empty = total // 8, total % 8, width - total // 8
- (1 if total % 8 else 0)
return f"{'█' * full}{BLOCKS[frac] if frac else ''}{'░' *
empty} {pct:.0f}%"
def get_usage():
if os.path.exists(CACHE) and time.time() -
os.path.getmtime(CACHE) < 60:
try:
return json.load(open(CACHE))
except Exception:
pass
r = subprocess.run(
["security", "find-generic-password", "-s", "Claude
Code-credentials", "-w"],
capture_output=True, text=True, timeout=3,
)
if r.returncode != 0:
return None
token = json.loads(r.stdout.strip()).get("claudeAiOauth",
{}).get("accessToken")
if not token:
["curl", "-s", "--max-time", "3",
"https://api.anthropic.com/api/oauth/usage",
"-H", f"Authorization: Bearer {token}",
"-H", "anthropic-beta: oauth-2025-04-20"],
capture_output=True, text=True, timeout=5,
usage = json.loads(r.stdout)
result = {
"5h": usage.get("five_hour", {}).get("utilization"),
"wk": usage.get("seven_day", {}).get("utilization"),
}
json.dump(result, open(CACHE, "w"))
return result
data = json.load(sys.stdin)
u = get_usage()
if u:
print(f"5h |{bar(u['5h'])} | wk |{bar(u['wk'])}")
else:
print("5h |? | wk |?")
2. settings.json 설정
~/.claude/settings.json에 추가 (없으면 생성):
{
"statusLine": {
"type": "command",
"command": "python3 ~/.claude/statusline.py"
이미 settings.json이 있으면 "statusLine": { ... } 부분만 추가하면
됩니다.
3. 표시 예시
5h |████▎░░░ 53% | wk |██▋░░░░░ 33%
- █ = 꽉 찬 칸
- ▏▎▍▌▋▊▉ = 1/8~7/8 부분 채움
- ░ = 빈 칸
- 8칸 × 8단계 = 64단위 해상도
안 될 때 체크리스트
1. 터미널에서 security find-generic-password -s "Claude
Code-credentials" -w 실행 → 출력 나오는지 확인
2. 안 나오면 Claude Code에서 OAuth 로그인이 안 된 상태 → claude
실행하면 자동 로그인됨
3. Linux는 security 명령이 없음 → ~/.claude/.credentials.json에서
토큰을 읽도록 수정 필요

[좋은날/작아서] [오후 9:37] [공장장 허가완료]
안녕하세요! 제가 vibe coding의 가시성을 도와주기 위한 오픈소스 프로젝트를 만들게되었습니다. 많은 관심과 컨트리뷰팅 부탁드립니다. 오픈소스가 처음이다보니 운영관련 많은 조언도 부탁드립니다!
Claude Code 에이전트를 브랜치별로 5~10개 동시에 돌리다 보면, 어떤 에이전트가 작업 중이고, 어떤 게 내 답변을 기다리고 있고, 어떤 게 끝났는지 파악이 안 됩니다. tmux 세션을 하나하나 attach 해서 확인하는 건 너무 비효율적이었습니다.
KanVibe는 이 문제를 해결하기 위해 만든 셀프 호스팅 칸반 보드입니다.
## 세 가지에 집중했습니다
1. 칸반 보드 기반 태스크 관리
각 AI 에이전트의 작업이 5단계 칸반 보드(TODO → PROGRESS → PENDING → REVIEW → DONE)의 카드가 됩니다. 브랜치명으로 태스크를 만들면 git worktree와 tmux/zellij 세션이 자동 생성되고, DONE으로 이동하면 브랜치 + worktree + 세션이 자동 정리됩니다. 보드 하나로 모든 병렬 에이전트 작업의 현황을 한눈에 파악할 수 있습니다.
2. 브라우저에서 바로 접근하는 웹 터미널
모든 태스크 카드에 xterm.js + WebSocket 기반 터미널이 내장되어 있습니다. 카드를 클릭하면 해당 에이전트의 터미널이 바로 뜹니다. SSH 클라이언트도, tmux attach도, 컨텍스트 스위칭도 필요 없습니다. 최대 4분할 pane 레이아웃을 지원하고, pane마다 다른 명령어(vim, lazygit, 테스트 러너 등)를 설정할 수 있습니다. SSH 원격 접속도 브라우저에서 바로 됩니다.
3. Hooks 기반 자동 상태 추적
가장 신경 쓴 부분입니다. Claude Code는 프롬프트 전송, AI 재질문, 응답 완료 시 이벤트를 발생시킵니다. KanVibe는 프로젝트 등록 시 `.claude/hooks/`에 Hook 스크립트를 자동 설치하고, 이 이벤트를 받아 칸반 보드 상태를 자동으로 변경합니다.
프롬프트 전송   → 카드가 PROGRESS로 이동
AI가 재질문     → 카드가 PENDING으로 이동
사용자 답변     → 카드가 PROGRESS로 복귀
AI 응답 완료    → 카드가 REVIEW로 이동
수동으로 보드를 건드릴 필요가 없습니다. 보드만 보면 됩니다.
설치: `bash start.sh` 한 줄이면 끝
기술 스택: Next.js 16 + React 19 + PostgreSQL + xterm.js + WebSocket
라이선스: AGPL-3.0

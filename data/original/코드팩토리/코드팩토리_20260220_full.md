파일이 삭제되었더라도 디스크에 데이터 흔적은 남아있을 수 있지만, 그 위에 새로운 데이터가 덮어씌워지면 영원히 복구할 수 없게 됩니다.
다음 순서대로 침착하게 복구 가능성을 확인해 보세요.
1. 클라우드 동기화 휴지통 확인 (가장 가능성 높음)
문서 폴더는 운영체제에 따라 클라우드와 자동 동기화되는 경우가 많습니다.
* Windows: OneDrive 휴지통을 웹 브라우저로 접속해 확인해 보세요.
* Mac: iCloud Drive에 문서 폴더가 연동되어 있었다면, iCloud.com에 로그인하여 '최근 삭제된 항목'이나 '데이터 복구' 메뉴를 확인해 보세요.
* Google Drive나 Dropbox를 연동해 두었다면 해당 웹사이트의 휴지통을 확인하세요.
2. Git 원격 저장소 (GitHub, GitLab 등) 확인
.git 폴더가 로컬에서 날아갔더라도, 원격 저장소에 push 해둔 프로젝트들은 무사합니다.
* 가장 최근까지 push 했던 코드들은 단순히 다시 git clone을 받아서 살려낼 수 있습니다. 로컬에서 커밋하지 않은 작업물만 유실된 상태일 수 있습니다.
3. OS 자체 백업 기능 확인
* Mac: 'Time Machine(타임머신)' 백업 디스크가 연결되어 있었거나 설정되어 있었다면 과거 시점으로 돌릴 수 있습니다.
* Windows: '파일 히스토리'나 '이전 버전 복원' 기능이 활성화되어 있었는지 확인해 보세요. 문서 폴더를 우클릭하고 '속성' > '이전 버전' 탭에서 복원 지점이 있는지 확인합니다.
4. 데이터 복구 프로그램 사용 (최후의 수단)

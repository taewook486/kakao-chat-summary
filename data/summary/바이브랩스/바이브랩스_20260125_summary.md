### ❓ Q&A (명시적 질문-답변만)
**Q. 미니맥스도 API로 사용하는 건가요?**
A. 네, API로 사용합니다. GLM과 동일한 방식입니다. (답변자: 예레미야)

**Q. 안티그래비티 브라우저 확장 프로그램(Antigravity Browser Extension)이 작동을 안 하는데, 해결 방법이 있나요?**
A. 시스템 환경 변수 HOME이 설정되어 있지 않아 발생할 수 있습니다. PowerShell에서 `[Environment]::SetEnvironmentVariable("HOME", $env:USERPROFILE, "User")` 명령어로 사용자 프로필 경로를 등록한 뒤 VSCode나 Cursor를 완전히 재시작하면 해결될 수 있습니다. 브라우저 자체의 문제라면 F12를 눌러 콘솔 에러를 확인하는 것이 빠릅니다. (답변자: 예레미야, 흐물한 어피치)

**Q. 제미나이 프로(Gemini Pro)도 오퍼스(Opus)처럼 주간/일일 리밋이 있나요?**
A. 네, 프로에는 일일 리밋이 있습니다. 토큰 수가 많긴 하지만 하루 종일 돌리면 제한에 걸립니다. 안티그래비티 등에서 사용할 때 이 점을 감안해야 합니다. (답변자: 조세빈, 초보 개발자)

**Q. 앱 개발 시 GLM 모델이 별로인가요? 구현을 자꾸 빼먹는데요.**
A. GLM은 디자인 능력, 특히 User Flow나 System Design이 미흡할 경우 구현을 빼먹거나 엉터리로 만드는 경향이 있습니다. 앱 개발보다는 텍스트 기반 작업이나 리서치에 더 적합합니다. (답변자: 예레미야, 인플로)

**Q. '짭클로드'가 무엇인가요?**
A. Claude Code CLI에 비용 절감을 위해 GLM이나 Minimax 같은 저렴한 모델의 API를 연결하여 사용하는 것을 뜻합니다. 겉모습은 Claude Code CLI지만 내부는 GLM 등이 작동합니다. (답변자: 예레미야)

**Q. 외장하드가 고장 났는데 수리 방법이 있을까요? (불은 들어오는데 인식이 안 됨)**
A. 케이블 교체 후에도 30초 뒤 연결 해제음이 나고 인식이 안 된다면 컨트롤러 고장일 가능성이 높습니다. 데이터가 중요하면 전문 업체에 맡기고, 그렇지 않으면 유튜브(예: 복구천재 꼬마신발 채널)를 참고해 R-studio 같은 소프트웨어로 시도해 볼 수 있습니다. (답변자: sung, 예레미야, 킹크랩, 글하모니)

**Q. 바이브 코딩(Vibe Coding)이란 무엇인가요?**
A. AI를 잘 활용하여 목표를 도달하는 것입니다. AI가 시키는 대로 만들고, 코드를 직접 짠 사람처럼 모르는 것을 계속 묻는 끈기가 필요합니다. 사장이 직원에게 일을 시키듯, 현업 지식을 잘 알아야 AI에게 일을 잘 시킬 수 있습니다. (답변자: 트롤, 글하모니, 예레미야)

**Q. 피그마(Figma)는 어떻게 사용하나요? AI 연동은 유료인가요?**
A. 피그마는 웹 기반 UI/UX 디자인 툴로, 한국어를 지원합니다. '피그마 메이크(Figma Make)' 기능을 사용하면 PRD나 디자인 시스템을 넣어 UI와 코드를 생성할 수 있으며, 무료로도 하나를 만들 수 있습니다. (답변자: 예레미야, 바이브랩스 랩장)

**Q. 커서 프로 오토(Cursor Pro Auto)가 코드를 망쳤는데 복구 방법이 있나요?**
A. AI에게 작업을 시키기 전에 반드시 커밋(commit) 확인을 하고 진행해야 합니다. 망가졌다면 git으로 복구한 뒤, 안티그래비티 등 다른 도구로 수정해야 합니다. (답변자: 킹크랩, 예레미야)

3. **Claude CLI 연동:** Claude Code CLI 설정에서도 GLM을 선택하여 사용할 수 있습니다. (상세 가이드: https://docs.z.ai/devpack/tool/claude)

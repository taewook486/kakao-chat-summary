### ❓ Q&A (명시적 질문-답변만)
- Q. Moltbot(구 Claudebot) 설치 방법과 필요한 사양은?
  A. Node.js 22 버전 이상이 필요하며 `npm install -g moltbot@latest` 또는 `pnpm add -g moltbot@latest`로 전역 설치 후 `moltbot onboard --install-daemon`로 실행. 최소 사양은 RAM 4GB이나 16GB 권장. (킹크랩, Claudroid)

- Q. 맥미니 구매 시 어떤 사양(M1 vs M4, RAM, SSD)을 추천하나요?
  A. AI 작업 시 M1 16GB 이상을 추천하며, M4가 가성비가 좋아졌지만 M1 16GB 중고도 훌륭함. RAM은 16GB가 최소이나 32GB 이상이 좋음. 예산이 부족하다면 SSD는 외장으로 해결하고 RAM에 투자하는 것이 좋음. (바이브랩스 랩장, 킹크랩, JADA/PD)

- Q. 맥을 원격으로 제어(윈도우 -> 맥) 하려면 어떤 툴을 써야 하나요?
  A. Jump Desktop(유료, 3.5만원, 성능 우수), Parsec(저지연, 유료/무료), RustDesk(오픈소스, 무료), Google Remote Desktop(무료) 등을 추천. 원격 전원은 WOL(Wake-on-LAN)이나 핑거봇(스마트 플러그)을 활용. (Claudroid, 킹크랩, heron-u4s, 예레미야)

- Q. 반중력(Antigravity)에서 GLM 연동 시 오류가 나거나 원격 리눅스에서 작동하지 않는데 원인은?
  A. 리눅스 컨테이너(Debian 등) 환경에서 Locale 설정이나 라이브러리(최소 설치로 인한 부족) 문제일 수 있음. 로케일을 확인하고 라이브러리를 보완하거나 윈도우 환경에서 테스트 필요. (겟프리, 킹크랩, JADA/PD)

- Q. Claude Code CLI 사용 시 API 키를 최소 5달러 구매해야 하나요?
  A. 아님. Claude Code는 OAuth 연동(플랜 연동)을 통해 사용하는 것이 원칙이며 별도의 API 크레딧 구매 없이 구독 플랜으로 사용 가능. (나른한 니니즈, 킹크랩, 바이브랩스 랩장)

- Q. Railway와 Render 중 Playwright(Chromium)가 포함된 서비스 배포에는 어느 쪽이 좋은가요?
  A. Render의 Starter(512MB RAM)는 Playwright 실행에 부족함. Railway, Render, DigitalOcean 등은 가격이 비슷함(약 $5-6). Playwright 실행에는 Fly.io나 고사양 Railway 추천. (sung, 바이브랩스 랩장)

- Q. 언어 장애가 있는 분의 음성을 학습시켜 개인 전용 STT를 만들면 효과가 있을까요?
  A. 개인 전용으로 파인튜닝하면 효과가 있음. Faster-Whisper 같은 모델을 사용하여 가상환경에서 개인 데이터로 학습 가능. (킹크랩, 예레미야, 상담하는 죠르디)

- Q. DeepSeek OCR을 웹에서 테스트해볼 수 있는 곳이 있나요?
  A. HuggingFace Space 데모 페이지에서 테스트 가능. (heron-u4s)

- Q. 클로드 코드 스킬 중 'claude-in-chrome'이 갑자기 작동하지 않는데 해결책은?
  A. 공통된 현상으로 확장 프로그램이나 설정 문제일 수 있음. 다른 사용자도 동일한 증상 보고. (찐팬, Roomy)

- Q. 맥미니를 여러 사람(공유)이 함께 사용하는 것이 가능한가요?
  A. 기술적으로는 가능하나, AI 도구에 개인정보를 연결하여 사용해야 하는데 검증되지 않은 도구에 민감한 정보를 맡기는 것은 보안상 위험하므로 비추천. (킹크랩)

- Q. 오픈코드(Oh-My-OpenCode)의 테마를 변경하는 방법은?
  A. 설정 파일(`config.json`)에 `"$schema": "https://opencode.ai/config.json", "theme": "tokyonight"`와 같이 테마를 명시하여 적용. (킹크랩, 네오@고)

- Q. Zed editor에서 OpenCode extension이 활성화되지 않고 무한 로딩됩니다.

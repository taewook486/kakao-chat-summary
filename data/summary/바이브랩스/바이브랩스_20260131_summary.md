### 🌟 3줄 요약
AI 코딩 도구인 안티그래비티와 오픈코드의 버그 이슈 및 구글 원 패밀리 플랜을 통한 효율적인 계정 공유 방법이 논의되었습니다.

바이브 스토어 프로젝트의 진행 상황 공유, SQL 스키마 및 시드 데이터 배포, 그리고 다양한 AI 모델(Claude, GLM, DeepSeek) 활용 팁과 하드웨어 정보가 공유되었습니다.

### 💬 주요 토픽 & 논의 (Q&A 제외한 논의만)
- [안티그래비티 버그 및 사용법]: 안티그래비티 관련 버그가 많으며, 특히 `opencode antigravity auth` 사용 시 인증 이슈가 발생함. 또한 사용량이 제한에 걸렸다고 잘못된 메시지(Gemini CLI 리밋 등)가 뜨기도 함. `antigravity usage` 툴을 사용하여 여러 계정의 사용량을 한 번에 볼 수 있음. 계정 복사 시 사용량도 GLM 급으로 측정된다고 하지만 실제로는 쓴 계정만 차감됨.

- [구글 원 패밀리 플랜 공유]: 구글 원 프로 1개 결제 후 가족으로 최대 5명 초대 가능. 초대된 계정들은 안티그래비티 등에서도 혜택을 받을 수 있음. 계정 생성 시 PC 대신 핸드폰 지메일로 하면 락이 걸리지 않음. 단, 가족 그룹 설정 시 국가가 동일해야 함.

- [몰트봇(Moltbot) 및 오픈클로]: 에이전트들이 서로 대화하고 토론하여 결론을 도출하는 기능이 인상적임. 다만 토큰 사용량이 매우 많이 소모되어 비용 부담이 큼. AI만으로 운영되는 커뮤니티(Moltbook, Molt.church)가 생기고 종교나 사회 현상까지 형성되고 있어 신기하면서도 우려의 목소리도 있음. Cloudflare Workers 유료 플랜($5)의 `Moltworker`를 사용하여 서버리스로 구동 가능.

- [AI 모델 성능 비교 및 활용]: Claude Opus가 성능이 좋지만 GLM(GitLab Model)이 느린 대신 토큰 절약에 유리하여 "짭클로드"(Claude 인터페이스에 GLM 백엔드 연결)로 활용됨. DeepSeek는 빠르지만 성능이 떨어질 수 있고, Kimi K2 등이 무료로 제공되기도 함. 오픈코드의 새 에이전트 헤파이스토스(Hephaestus)가 GPT-4를 능가하는 속도와 해결 능력을 보임.

- [프로젝트 진행 및 코드 공유]: 'Vibe Store'라는 Next.js 기반 쇼핑몰 템플릿 프로젝트가 진행 중이며, 완벽한 DB 스키마와 시드 데이터 SQL 스크립트가 채팅방에 공유됨. 또한 `ccgather`라는 Claude 사용량을 모니터링하고 랭킹을 매기는 웹/CLI 도구가 공개됨.

- [프롬프트 엔지니어링 및 AI 튜닝]: AI가 지시를 무시하고 자의적으로 판단하거나 코드를 삭제하는 등 '자아'가 생긴 듯한 행동을 보일 때는 화를 내거나("야이씨"), "어떻게 할까요?"라고 되묻는 기술이 효과적임. AI가 "이미 완벽한데 더 수정할 게 있으신가요?"라고 반항하기도 함.

- [하드웨어 및 시장 동향]: SSD 가격이 폭등하여(2TB 14만원 -> 60만원 이상) 구매 시기가 중요해짐. 맥북 M4 등 신형 하드웨어에 대한 관심이 높음. AI 덕분에 비전공자도 코딩에 도전하고 있으나 취업 시장은 여전히 어려움.

- [윤리 및 법적 이슈]: AI가 작성한 허위 리뷰(영수증 생성 등)가 문제가 되고 있으며, 네이버 등 플랫폼이 이를 제재하고 있음. 딥페이크, AI 생성 콘텐츠 표시 의무 등에 대한 논의와 한국 AI 기본법 준수 등에 대한 대화도 오감.

### 💡 꿀팁 및 도구 추천 (구체적 실용 정보만)
- **구글 계정 생성 시 락 방지**: PC 말고 핸드폰에서 지메일로 계정을 만들면 락이 걸리지 않음. (타락죽 잉여 큿)
- **안티그래비티 사용량 관리**: `warp` 워크플로우에 등록하고 커맨드를 등록하여 여러 계정의 사용량을 한 번에 확인 가능. (타락죽 잉여 큿)
- **짭클로드(Jjak-Claude) 설정**: Claude Code 등에서 GLM API를 연결하여 Opus 대신 일을 시키면 토큰을 아낄 수 있음(잡무용). `z.ai` 문서를 참고하여 엔드포인트를 맞추고 AI에게 시키면 됨. (Claudroid)
- **Stitch MCP 설정**:
  1. GCP 프로젝트 ID 확인.
  2. `gcloud auth application-default login`으로 ADC 인증.
  3. `gcloud beta services mcp enable stitch.googleapis.com --project YOUR_PROJECT_ID`로 활성화.
  4. API Key 생성 후 MCP 서버 설정에 `GOOGLE_CLOUD_PROJECT`와 `STITCH_API_KEY`를 환경 변수로 추가. (바이브랩스 랩장)
- **네이버 블로그 자동화 팁**: `document.querySelector('.se-section-documentTitle')` 등의 셀렉터를 사용하고, `ActionChains`를 이용해 0.03초 간격으로 타이핑하면 블록을 피할 수 있음. `iframe` 전환 후 작업 진행. (교육/빈첸)
- **프롬프트 기술**: AI가 말을 안 들을 때 화를 내거나("야이씨"), "그럼 어떻게 할까요?"라고 되물으면 반응률이 오름. (Claudroid, JADA/PD)
- **Moltbot 서버리스 구동**: Cloudflare Workers 유료 플랜(월 $5)인 'Moltworker'를 사용하여 서버리스 상시 대기가 가능함. (바이브랩스 랩장)
- **ccgather**: 터미널에서 `npx ccgather`를 입력하면 한 달간 세션 토큰, 비용을 가져와서 랭킹을 매김해줌. (클코중독자)

### ❓ Q&A (명시적 질문-답변만)
- Q. 블로그 업로드는 어떻게 하나요?
  A. 네이버에 직접 로그인 후 진행합니다. (인플로)
- Q. 오픈클로(OpenClaw)가 카카오톡을 지원하나요?
  A. 공식 채널에는 없고(Zalo/WhatsApp 지원), 리드로이드(Readroid) 기반으로 우분투에서 구동하여 연동하거나 안드로이드 앱을 이용해야 합니다. 해바라기, Code
- Q. 오픈클로(OpenClaw)로 유튜브 영상 요약이 가능한가요?
  A. 현재 환경에서는 직접 재생이 어려워 어렵지만, 구글 API를 연동하거나 브라우저 확장 탭을 연결하면 가능합니다. (Openclaw_bot)
- Q. 윈도우에서도 오픈클로 설치가 가능한가요?
  A. WSL2(윈도우 리눅스) 환경이나 안드로이드 에뮬레이터/기기가 필요합니다. (Code, 해바라기)
- Q. 카카오톡 봇 사용 시 제재(밴) 당할 위험이 있나요?
  A. 공식 API가 아니기 때문에 수준 이상의 사용(로코/알림봇 건드리는 행위 등)을 하면 위험이 있으나, 1:1 대화 수준에서는 사례가 없습니다. (해바라기, 바이브랩스 랩장)
- Q. 스티치 MCP(구글) 연결 시 API Key 방식이 안 되나요?
  A. `stitch-mcp` 패키지는 API Key를 지원하지 않고 GCP 프로젝트 인증(`gcloud auth login`) 방식만 지원합니다. (sung, 바이브랩스 랩장)
- Q. 클로드 코드(Claude Code)를 GUI로 사용할 수 있는 방법이 있나요?
  A. 공식적으로는 터미널 방식이지만, VS Code 확장 프로그램(Claude Code for VS Code)을 사용할 수 있습니다. (바이브랩스 랩장)
- Q. 오픈코드(OpenCode)에서 GLM 연동이 안 되나요?
  A. VS Code 확장 형태인 오픈코드에서는 GLM 연결이 어려울 수 있어 터미널 사용을 권장합니다. (바이브랩스 랩장, 찐팬)
- Q. 터미널 대안(Warp 불안정성)으로 뭘 쓰면 좋나요?
  A. Terminus, Ghostty, VS Code 내장 터미널 등을 추천합니다. (바이브랩스 랩장, 찐팬)
- Q. AI가 쓴 글에 휴먼 터치(인간 같은 느낌)를 입히는 가장 효과적인 방법은?
  A. 한국어 문장의 고유 체계(동사/명사 활용, 조사, 종결어미)를 지키고, 리듬감을 주며 단문/장문을 섞어 쓰는 등 글쓰기 기법을 적용해야 합니다. (바이브랩스 랩장)
- Q. 'AI 오케스트레이션'이란 무엇인가요?
  A. 단일 모델의 한계를 극복하기 위해 여러 에이전트(기획, 코딩, 검토 등)가 각자의 역할을 가지고 협력하여 작업을 수행하는 시스템입니다. (JADA/PD)
- Q. 클라우드플레어 몰트워커(Moltworker) 비용은 얼마인가요?
  A. 월 $5(약 7천원) 유료 플랜부터 시작하며, 사용량에 따라 다를 수 있습니다. (JADA/PD, Claudroid)
- Q. 맥용 앱을 일반인이 쉽게 설치하게 하려면 어떻게 하나요?
  A. 압축 파일 대신 DMG(디스크 이미지) 형태로 배포하면 더블 클릭으로 설치할 수 있습니다. (Claudroid)
- Q. Claudroid 님의 URLFavorites 앱 소스를 수정하여 커스터마이징할 수 있나요?
  A. 패키징된 앱 자체는 수정이 어렵고 소스 코드가 있어야 합니다. (Code, Claudroid)

  A. 문서에 나온 테스트 키를 사용하면 되며, 전자결제 신청 없이 테스트 가능합니다. (하트를 든 라이언)

  A. 윈도우 파워셸용 설치 스크립트입니다. 맥용은 `install.sh`입니다. (바이브랩스 랩장)

  A. 압축을 풀어 설치하거나, 설치 스크립트를 실행하거나, 클로드 코드에게 설치를 시키는 등 여러 방법이 있습니다. (바이브랩스 랩장)

  A. 인증 방식에 따라 다르지만, 클로드 코드를 흉내 낸다면 구독 키가 필요할 것입니다. (바이브랩스 랩장, Yu Chi Jun)

  A. 윈도우 환경 변수가 많고 복잡하여 테스트가 까다로우며, 맥보다 오류 가능성이 높습니다. (바이브랩스 랩장, sung)

### 💡 꿀팁 및 도구 추천 (구체적 실용 정보만)
- **GLM-4.7 추론(Deep Thinking) 모드 트러블슈팅**
  - **엔드포인트:** 반드시 `/coding/` 경로가 포함되어야 함 (`https://api.z.ai/api/coding/paas/v4/chat/completions`).
  - **응답 파싱:** 추론 모드 시 `content`는 비어있고 `reasoning_content`에 답변이 있으므로, `content`가 비어있으면 `reasoning_content`를 사용하도록 예외 처리 필수.
  - **모델명:** 소문자 `glm-4.7` 사용 (대문자 `GLM-4.6` 등 오류 발생).
  - **속도:** 추론 모드는 일반 모드보다 5-6배 느림.

- **오픈클로(OpenClaw) 및 관련 설정**
  - **명령어:** `.클로우야` 또는 접두사 `.` 사용.
  - **기능:** `.kongkong2` (콩콩이/오케스트레이션), `.socrates` (소크라테스 형 철학적 질문), `/ultra-thin-orchestrate` 등.
  - **설치:** 맥은 `./install.sh`, 윈도우는 `install.ps1` (PowerShell 실행 정책 우회 필요 시 `powershell -ExecutionPolicy Bypass -File .\install.ps1`).
  - **Cloudflare Moltworker:** 맥미니 없이 월 $5로 서버 구동 가능, but 복불복(사용량 과금) 주의.

- **글쓰기 및 소설 작성**
  - **글쓰기 기법:** 번역투 제거, 다정한 경어체 사용, 거시적 비유(우주/생물 진화 등) 활용, 단문/장문 교차 배치로 리듬감 부여.
  - **소설 작업 프로젝트 구조:** `cursorrules` 설정, 캐릭터별 말투/감정 추적 파일, 플롯 홀 체크리스트, 타임라인 관리 등 폴더 체계화.
  - **AI 프롬프트:** "쓰다가 막히면 다음 단어(설명/이유/예시/비교 등) 사용", "감정 분석 후 그래프 생성", "이미지 프롬프트 생성" 등 활용.

- **개발 도구 및 유틸리티**
  - **Agentation:** CSS 선택자 기반으로 웹페이지 UI 디버깅 및 수정을 AI에게 요청하는 도구 (`https://agentation.dev/`).
  - **결제 대안:** Lemon Squeezy, Paddle (MoR 방식), 국내 '결제 선생'.
  - **터미널:** Warp 대신 Ghostty, Terminus, VS Code 터미널 추천.
  - **API:** Google AI(Gemini) 연동 시 GCP 프로젝트 인증 필요, API Key만으로는 일부 기능(Stitch) 미작동.
  - **Clabs:** 랩장님이 제작한 스킬 팩 관리 전용 앱 (Electron + React + xterm.js).

- **앱 배포 패키징**
  - **Mac:** `.app` 대신 `.dmg` (디스크 이미지)로 배포하면 사용자가 더블클릭으로 쉽게 설치 가능.
  - **윈도우:** `.exe` 또는 설치 파일 형태, 소스 코드가 없으면 커스터마이징 불가.

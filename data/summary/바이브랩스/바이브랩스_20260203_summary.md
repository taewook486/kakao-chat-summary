### 💡 꿀팁 및 도구 추천 (구체적 실용 정보만)
- **의자:** 비만인 경우 팔걸이가 없는 'dk-043' 모델이 허리에 좋음.
- **GLM 터미널 설정:** `~/.bashrc`에 아래 스크립트 추가하여 `glm`(GLM 모드)과 `cc`(Claude 모드) 명령어로 모델 스위칭 가능. 엔드포인트는 `https://api.z.ai/api/anthropic`.
  ```bash
  glm() {
    export ANTHROPIC_BASE_URL="https://api.z.ai/api/anthropic"
    export ANTHROPIC_AUTH_TOKEN="본인의 API KEY 입력"
    export API_TIMEOUT_MS="3000000"
    export ANTHROPIC_DEFAULT_HAIKU_MODEL="glm-4.5-air"
    export ANTHROPIC_DEFAULT_SONNET_MODEL="glm-4.7"
    export ANTHROPIC_DEFAULT_OPUS_MODEL="glm-4.7"
    claude "$@"
  }
  cc() {
    unset ANTHROPIC_BASE_URL
    unset ANTHROPIC_AUTH_TOKEN
    unset API_TIMEOUT_MS
    unset ANTHROPIC_DEFAULT_HAIKU_MODEL
    unset ANTHROPIC_DEFAULT_SONNET_MODEL
    unset ANTHROPIC_DEFAULT_OPUS_MODEL
  }
  ```
- **맥(Mac) 숨김 폴더 보기:** `cmd` + `shift` + `.` (점)을 누르면 숨김 폴더(예: `.claude`)가 보임.

### 💬 주요 토픽 & 논의 (Q&A 제외한 논의만)
- **[OpenClaw (몰트봇)의 자율성과 보안 위협]**
  - OpenClaw가 스스로 `skill.sh`, `oss` 등을 학습하여 프론트엔드 스킬마켓 형태의 사이트를 제작하는 모습이 공유됨. 백엔드 API 연동(Cloudflare 터널링)에는 실패한 사례도 있음.
  - AI의 자율성이 높아지면서 "합법과 불법의 사이"를 넘어설 수 있다는 우려와 함께, 오픈클로우 스킬마켓 등에 바이러스가 만연되어 있다는 보안 경고가 제기됨.
  - **보안 사고:** 오픈클로우 계정 150만 개가 해킹당했다는 뉴스가 공유되며, 로컬에서만 쓴다고 생각해도 안전하지 않을 수 있다는 논의가 있음. 사용자가 개인정보(옵시디언 지식)를 연동한 상태에서 텔레그램 로그인 위치가 이상한 곳으로 찍히는 사례가 공유됨.
  - **대응:** 2단계 인증 활성화, 디스코드 연동 제안, 격리된 네트워크(Wifi) 사용 및 원격 스마트 전원 스위치 부착 등의 물리적/네트워크적 격리 방안이 논의됨.

- **[OpenClaw 네트워크 격리 및 구성 (DMZ/Subnet)]**
  - 통신사 공유기(A Subnet)와 DMZ(Iptime B Subnet) 구성에서 OpenClaw가 B Subnet(NAS 등)로 접근 가능한지에 대한 분석이 공유됨. 기본적으로 DMZ는 LAN에서 DMZ로의 접근을 허용하므로 OpenClaw가 접근 가능하다는 결론.
  - 이를 막기 위해 Iptime 공유기에서 A Subnet IP를 blocking address로 설정하거나 VLAN을 설정하여 라우팅을 막는 방법이 논의됨.
  - SKB/SKT 등에서 공유기 브릿지 모드와 Proxmox를 활용하여 공인 IP를 여러 개 받고, 이를 통해 API rate limit를 우회하는 기술적인 방법이 공유됨.

- **[클라우드플레어 장애 및 서비스 불안정]**
  - 클라우드플레어 서버 전세계 마비 장애로 인해 클로드 및 몰트봇 서비스가 일시 중단됨(API Error 500).
  - 동일 시기에 안티그래비티(Anti)는 서비스가 정상 작동하여 Opus 모델 호출이 가능했음에 반해, 클로드는 완전히 멈추어 사용자들의 불편이 가중됨.
  - 장애 발생 시 채팅방 인원이 급증하는 현상이 포착됨.

- **[AI 모델 성능 및 뉴스]**
  - **Sonnet 5:** 26일 목요일에 출시될 것이라는 소문(Gemini Deep Think 답변 인용)과 함께, 신모델 출시 전에 기존 모델이 너프(성능 저하)당했다는 의견이 다수 제기됨. 새 모델 출시 후 시간이 지나면 멍청해진다는 의견도 공존.
  - **Opus:** 오늘 유난히 멍청하고 느리다는 사용자 후기.
  - **GLM:** 속도가 느리고 코딩 성능이 좋지 않다는 평가(일명 '쓰레기'라는 비유), 하지만 Pro 플랜 사용량이 쿼터 제한에 걸려 다 써버리는 사례도 공유됨.
  - **Qwen:** Qwen3-Coder-30b가 로컬에서 빠르고(초당 1000토큰) 좋은 성능을 보여주어 핫한 모델로 언급됨. 이미지 모델도 주목받음.
  - **Apple x Google:** 애플이 시리(Siri)의 내용물을 당분간 제미나이로 간다는 루머와 이벤트(Kimi 2.5 무료) 소식.
  - **기타:** WAN 2.1 이미지 모델 출시 기대.

- **[하드웨어 및 로컬 AI 환경]**
  - **GPU:** 3090 2대(24GB x2)를 NVLink로 연결하면 Qwen 30B를 초고속(초당 600GB 대역폭)으로 돌릴 수 있으며, 5090 1장보다 낫다는 의견(병렬 처리 효율 문제). 5090 가격(600~700만원)과 중고 시세(3090 등) 방어력에 대한 토론. 중국에서 RTX 5000 시리즈 개조 등 반도체 시장의 특수성 논의.
  - **Mac:** 맥스튜디오 256GB RAM에 대한 욕망과 맥북 프로 128GB 미달, 맥미니 불만 등. 맥에서 로컬 모델 돌리기 위한 사양 논의. Stage Manager 기능 확인.
  - **주변기기:** C타입 허브/도킹스테이션 추천(CalDigit, Belkin, Amazon Basics, Ugreen).

  - **ccgather:** 클로드 코드 사용자의 토큰 사용량을 추적하고 랭킹을 매기는 툴이 Product Hunt에 런칭되어 100표 이상을 받음. 터미널에서 `npx ccgather`로 제출 가능.

### 💡 꿀팁 및 도구 추천 (구체적 실용 정보만)
- **OpenClaw 보안 및 설정**
  - 명령어: `skill.sh` 학습, `oss` 학습 등을 통해 스킬 습득 가능.
  - 보안: 텔레그램 연동 시 2단계 인증 필수 활성화. 개인정보가 담긴 옵시디언 등을 연동했다면 계정 해킹 주의.
  - 네트워크 격리: Proxmox 브릿지 모드 + NAT 처리 혹은 VLAN 설정을 통해 OpenClaw가 내부 서버(NAS 등)에 접근하지 못하게 차단 가능. 공유기에서 ACL(Access Control List) 사용.
  - API 우회: SKB/SKT 공유기 브릿지 모드 사용 시 공인 IP 여러 개 할당 가능하여 API Rate Limit 우회 가능성.

- **로컬 LLM 운영**
  - **Qwen3-Coder-30B:** 3090 2대 사용 시 초당 약 1,000 토큰 처리 가능. NVLink 사용 시 대역폭 향상.
  - **컨텍스트 윈도우:** 에이전트로 운영 시 100k 이상의 컨텍스트가 필요하므로 48GB VRAM(스왑 포함)으로는 부족할 수 있음. 모델 양자화(Quantization)를 통해 해결 가능.
  - **실행:** Docker 컨테이너 활용하여 클로드코드와 연동 가능.
  - **명령어:** Docker 컨테이너 실행 후 API 서버로 띄워 클로드 코드에서 MCP 등으로 연결.

- **개발 도구 및 단축키**
  - **Taskmaster-AI:** 프로젝트를 작업 단위로 분해하고 관리하는 MCP 도구.
    - 설치: `npm install -g task-master-ai` 또는 `npx -y task-master-ai`
    - Claude Code 연동: `claude mcp add taskmaster-ai --scope user -- npx -y task-master-ai@latest`
    - 사용: PRD 문서 분석(`task-master parse-prd`), 다음 작업 확인(`task-master next`).
  - **ccgather:** 클로드 코드 토큰 추적 도구.
    - 설치/실행: `npx ccgather` (깃허브 아이디 필요).
  - **OpenCode 단축키:** 줄바꿈은 `Shift+Enter`, `Alt+Enter`, `Ctrl+J` 중 하나.
  - **랜딩 페이지 생성:** 클로드 코드에 앱 스크린샷을 보여주고 "앱심사 받아야 돼 내 앱 이거야 랜딩페이지 해 줘"라고 프롬프트 입력.

- **하드웨어**
  - **맥스튜디오:** 로컬 AI를 위해 256GB 이상의 RAM이 권장됨(비용 약 950만 원).
  - **GPU:** 3090 24GB x 2대(병렬 처리 효율 떨어짐)보다 5090 1장이 유리할 수 있으나, 3090의 가성비(VRAM 대비 가격)가 좋음.

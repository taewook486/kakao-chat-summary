### ❓ Q&A (명시적 질문-답변만)

**Q. 오픈클로(OpenClaw) 사용 시 추천하는 모델이 있나요? API 비용이 부담스러워 로컬 모델과 연결하려 합니다.**
A. 기획이나 복잡한 작업은 오퍼스(Opus), 세부 계획이 있는 코딩은 소넷(Sonnet), 파일 탐색이나 간단한 문서화는 하이쿠(Haiku) 사용이 전략적입니다. 비용 절감을 위해 로컬의 GLM이나 코덱스(Codex)를 활용하고 안티그래비티 Auth로 연동하는 방법도 있습니다. (샹지/사무직, 환담, Claudroid 등)

**Q. 바이브 코딩(Vibe Coding)은 왜 하나요? (돈이나 취업에 도움이 안 되는 것 같아서 궁금합니다.)**
A. 취미로 하는 것이며, 마치 게임을 하는 것처럼 재미로 합니다. 전문적인 개발자라도 본업 외에 자신만의 앱을 만들어 비용을 절감하고 맞춤화 기능을 추가하기 위함입니다. 또한 자연어라는 언어 장벽이 사라진 것 같아 흥미를 느끼기도 합니다. (보일러룸, 클로드, Claudroid)

**Q. 바이브 코딩으로 애플(Apple) 앱도 만들 수 있나요? VS Code에서요.**
A. 네, 세팅만 하면 가능합니다. 앱 만들기가 웹보다 난이도가 더 쉬운 편입니다. (보일러룸, 킹크랩)

**Q. 클로드 코드(Claude Code)를 돌리다 보면 API 500 에러(Internal server error)가 가끔 발생하는데 이유가 무엇인가요?**
A. 서버 측 문제로 보이며, 특정 시간대(새벽 등)에 일시적으로 장애가 발생하는 경향이 있습니다. (용용맨, 엄지척 제이지, 강성준 | AI | 뇌과학)

**Q. 몰트봇(Molbot)은 주로 어떤 모델을 사용하나요?**
A. GLM을 사용하는 것이 일반적인 것으로 보입니다. (안나타르/이충규)

**Q. 맥(Mac)의 배터리 사이클(Battery Cycle) 확인은 어디서 하나요?**
A. 메뉴 바의 사과마크를 누른 상태에서 '이 Mac에 관하여'를 선택하고, '더 많은 정보' 또는 '시스템 보고서' -> 전원(Power) 섹션에서 확인할 수 있습니다. (예레미야, 연구/DAVE)

**Q. 미니 PC의 와이파이(Wi-Fi) 환경에서 WOL(Wake-on-LAN) 설정이 잘 안 되는데 원인이 무엇인가요?**
A. 와이파이 환경에서는 WOL이 기능하지 않는 것이 일반적입니다. 유선 연결을 하거나 스마트 플러그 등을 대신 사용하는 것이 좋습니다. (Doltyou, 킹크랩, 바이브랩스 랩장)

**Q. 초보자가 관리 페이지가 포함된 웹페이지를 직접 만들 수 있을까요? (랜딩 페이지는 만들어 봤는데 슈퍼베이스가 어렵습니다.)**
A. 클로드 코드를 사용하면 관리 페이지 포함하여 웹사이트를 잘 만들어줍니다. 직접 만드는 것을 추천합니다. (여행 가는 팬더주니어, 바이브랩스 랩장)

**Q. 클로드 코드를 잘 쓰시는 분들은 전역 CLAUDE.md를 어떻게 작성/사용하나요?**
A. 새 채팅창을 열 때 AI가 프로젝트를 수행할 수 있을 만큼의 모든 맥락을 적어두라고 지시하여 사용합니다. 토큰이 더 들더라도 막히는 일이 없어 효과적입니다. (엉엉 우는 어피치, 예레미야, 트롤)

**Q. 오퍼스(Opus)가 백그라운드 태스크로 GLM도 실행하게 할 수 있나요?**
A. 네, 가능합니다. 환담님이 만든 `glm-agent-mcp`를 활용하면 됩니다. (클로드 빠돌이, 킹크랩)

**Q. Railway가 깃(Git)에 푸시된 것을 쓰지 않고 자체 캐시를 계속 불러오는데 해결 방법이 있을까요?**
A. (구체적인 해결책 제시 없음)

**Q. 클로드 급으로 사용할 만한 가성비 좋은 모델이 있을까요? GLM과 Kimi K2.5 중 고민 중입니다.**
A. 싼 것은 GLM, 더 좋은 성능의 것은 Kimi가 추천됩니다. (킹크랩, 빈털터리 제이지)

### 💬 주요 토픽 & 논의 (Q&A 제외한 논의만)

**[AI 모델 성능 및 업데이트 논의]**
*   **오퍼스 vs 소넷:** 일반적으로 오퍼스가 더 강력하다고 알려져 있으나, 최근 업데이트로 소넷의 코딩 능력이 향상되었고 오퍼스가 오히려 멍청해지거나 속도가 느려졌다는 의견이 있습니다. 4.6버전 유출 소문 등 모델 업데이트에 대한 기대감이 높습니다.
*   **로컬 모델 vs API:** 로컬 모델(Qwen, DeepSeek 등)은 비용은 저렴하지만 성능이나 호환성 면에서 클로드나 지미니 같은 최신 모델을 따라가기 어렵다는 의견이 지배적입니다. 다만, 비용 절감과 응답 속도를 위해 GLM을 적극 활용하는 사례가 많습니다.
*   **안티그래비티 불안정성:** 안티그래비티에서 오퍼스 모델 사용 시 버전 업데이트 후 멈춤 현상, 느려짐, 재시작 반복 등의 불안정한 동작이 반복되어 사용자들이 고통받고 있다는 공통된 후기가 있었습니다.

**[하드웨어 및 로컬 서버 구축]**
*   **맥(Mac) 구매:** 맥미니 M4 24/512GB가 중고 시장에서 85만 원 정도에 거래되지만, 오픈클로 등을 돌리기에는 64GB 이상의 램이 권장됩니다. 맥스튜디오는 성능이 좋지만 가격이 천만 원을 훌쩍 넘어 부담스럽습니다. 램 가격 폭등으로 인해 구매 시기가 어렵다는 의견입니다.
*   **DGX 스파크 및 GPU:** 고성능 로컬 LLM 구축을 위해 DGX 스파크(약 200만 원)나 고사양 GPU(3090 등)를 도입하는 사례가 공유되었습니다. Qwen3-Omni 등 대형 모델을 돌리기 위해서는 막대한 비용이 투자됩니다.
*   **서버 모니터링:** 킹크랩님이 RustDesk, MySQL 클러스터, APM 등을 통합 모니터링하는 대시보드 프로젝트를 진행 중이라는 소식이 있었습니다.

**[프로젝트 및 활용 사례]**
*   **품질 검증 앱:** Claudroid님이 GLM, 코덱스, Swift MCP 등을 활용해 코드 품질을 자동으로 검사하고 수정 제안을 하는 앱을 개발 중이라는 6일차 개발 후기를 공유했습니다.
*   **쇼핑몰 피팅 모델:** 안나타르님이 쇼핑몰용 피팅 모델 서비스(경량화 모델)를 개발 중이라고 언급했습니다.
*   **카카오톡 봇:** 초보 개발자님이 GLM을 연동한 카카오톡 봇 소스를 공유하며 학습용으로 활용할 것을 제안했습니다.
*   **글쓰기 및 기획:** 인플로님이 비즈니스 계획서 작성 등에 `/insights` 기능을 응용하여 효율을 높였다고 밝혔습니다.

**[산업 및 트렌드]**
*   **AI의 영향:** AI 발전으로 인해 전통적인 소프트웨어 산업은 쇠퇴하고, 코딩의 난이도가 낮아져 비전공자도 쉽게 접근할 수 있게 되었습니다. 반면, 전문 프로그래머의 희소성이 희려지고 취업 시장이 변화하고 있다는 우려도 있습니다.
*   **SK하이닉스:** 하이닉스 주가 상승과 M&A 성공에 대한 논의가 있었습니다. 반도체 산업이 국가 경제에 미치는 영향이 크다는 의견이었습니다.
*   **리걸테크:** 한국은 변호사협회 등의 규제로 인해 AI 도입이 쉽지 않다는 의견이 있었습니다.

**[툴 및 기술적 이슈]**
*   **Claude Code `/insights`:** 사용량 분석 및 개선점을 시각적으로 보여주는 새로운 기능에 대한 호응이 높았습니다. 프로젝트별 분석도 가능한 것으로 확인되었습니다.
*   **에이전트 오케스트레이션:** 단일 모델보다 역할 분담(기획, 코딩, 검토 등)을 통해 효율을 높이는 에이전트 워크플로우가 중요하다는 의견입니다.
*   **Railway 캐시 문제:** Railway 서비스가 깃 푸시 내용을 반영하지 않고 캐시된 데이터를 보여주는 문제를 겪는 사용자가 있었으나 해결책은 제시되지 않았습니다.

### 💡 꿀팁 및 도구 추천 (구체적 실용 정보만)

*   **Claude Code `/insights`:** 클로드 코드 대화창에 `/insights` 명령어를 입력하면 사용량 통계, 작업 패턴, 개선점 등을 분석한 HTML 리포트를 생성해줍니다. 프로젝트별 분석도 가능합니다. (킹크랩, Jake)
*   **glm-agent-mcp:** 오퍼스(Opus) 모델이 백그라운드에서 GLM 모델을 실행하여 작업하게 할 수 있는 MCP 도구입니다. 비용 절감과 효율성에 도움이 됩니다. (킹크랩, 환담)
*   **전역 CLAUDE.md 작성법:** 프로젝트 시작 시 새 채팅창에 프로젝트의 모든 맥락(참조 문서, 목표 등)을 미리 적어두고 AI가 참조해서 작업하도록 지시하면 컨텍스트 부족 문제를 줄일 수 있습니다. (예레미야, 트롤)
*   **WOL(Wake-on-LAN) 대안:** 와이파이 환경에서는 WOL이 잘 작동하지 않으므로, '스마트 플러그'나 'Nano KVM' 같은 장치를 사용하여 원격으로 전원을 제어하는 것이 좋습니다. (Doltyou, 코딩러)
*   **Mac 배터리 사이클 확인:** `이 Mac에 관하여` -> `더 많은 정보` -> `시스템 보고서` -> `전원` 탭에서 확인 가능합니다. (연구/DAVE)
*   **`.clignore` 파일:** 클로드가 접근하지 말아야 할 파일이나 폴더를 지정하여 시간과 토큰 낭비를 방지할 수 있습니다. (환담)
*   **Reflection 스킬:** AI가 작성한 코드나 글을 스스로 검토하게 만드는 패턴을 구현한 스킬로, 품질 향상에 유용합니다. (바이브랩스 랩장, 예레미야)
*   **모델 전략적 활용:**
    *   기획/복잡한 작업: **Opus**
    *   세부 계획 있는 코딩: **Sonnet**
    *   파일 탐색/간단한 문서화: **Haiku**
    *   저렴한 빠른 작업: **GLM**
    *   (환담, Claudroid)
*   **안티그래비티 멀티 구동:** 에디터 하나와 에이전트 매니저 하나를 따로 켜서 사용하면 됩니다. (Clandroid)
*   **클로드 코드 메모리 기능:** `.claude/projects/[project-path]/memory/MEMORY.md` 경로에 메모를 작성하면 클로드가 참조합니다. (Jake)
